# MT Jukebox

Telegram Mini App for the community group. One queue. Everyone hears the same track.

Bot: [@Mtradiobot](https://t.me/Mtradiobot)

## Connect

1. Add `@Mtradiobot` to the group (admin).
2. Open the Mini App, or send `/jukebox` in the group.
3. First tap is **Join the room** (needed on iPhone).
4. Play / queue / upload from the phone.

Group name used at setup: SoftwareTesters. If the bot is not in that group yet, add it, then send `/jukebox`.
